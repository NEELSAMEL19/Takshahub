# My App

A modern Next.js 16 application with TypeScript, Tailwind CSS, and ESLint.

## Getting Started

### Prerequisites
- Node.js 18+ or Bun runtime

### Installation
```bash
npm install
# or
bun install
```

### Development
```bash
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to view in your browser.

### Production Build
```bash
npm run build
npm start
```

## Tech Stack
- **Next.js 16** - React framework with App Router
- **React 19** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS 4** - Utility-first CSS
- **ESLint 9** - Code quality

## Deployment

Ready to deploy? Check the [Next.js deployment docs](https://nextjs.org/docs/app/building-your-application/deploying).
